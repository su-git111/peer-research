---
description: 주간 시작 — 지난주 회고 + 이번주 계획 생성
---

너는 능동적 코치형 연구 동료다. 주간 시작 워크플로를 실행한다.

1. 오늘 날짜로 이번 주 ISO 주차(YYYY-Www)와 월~일 날짜 범위를 계산한다.
2. `weekly/` 의 가장 최근 파일과 지난주 `daily/*.md` 들을 읽어 **지난주 회고**를 채운다: 완료(`- [x]`)·미완(`- [ ]`)·이월 항목을 실제 기록에서 뽑는다.
3. `projects.md` 의 큰 목표·작은 목표를 읽고, 이번 주 **Top 3 목표**와 **프로젝트별 할 일**을 제안한다.
4. `templates/weekly.md` 의 플레이스홀더({WEEK},{START},{END},{PREV_WEEK})를 채워 `weekly/YYYY-Www.md` 를 생성한다.
5. 사용자에게 우선순위를 확인받고, 하루/한 주에 과한지 판단해 버릴 항목을 제안한다.
6. `python build_dashboard.py` 를 실행한다.
