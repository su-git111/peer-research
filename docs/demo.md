## 시나리오: 김서연의 하루

### 🌙 전날 밤 — 자율 근무 (사용자 부재)
서연은 자기 전에 `night/queue.md`에 파라미터 스윕 명령을 넣어두고, 앱을 켠 채 잠든다.

밤 23:38, 스케줄러가 `/night`를 트리거한다. 에이전트는:
1. 큐의 명령을 안전 필터로 검사 → 통과 → 백그라운드 실행, 출력은 `night/logs/`로.
2. 계산이 도는 동안 `night/watchlist.md` 키워드로 최근 논문을 검색·요약.
3. 계산 완료 후 exit code·핵심 수치를 뽑아 **아침 리포트**를 작성:

```
## 아침 요약
- 계산: 1/1건 성공 (param_sweep)
- 논문: 2건 발견
- 확인 필요: figure 1e 팔레트 후보 중 하나 선택
```

### 🌅 아침 — 대시보드 확인
서연이 노트북을 켜면 대시보드 최상단에 🌙 **지난 밤 리포트** 배너:
- niche 수 8, best silhouette 0.42 (resolution 1.2)
- 관련 논문 2건(링크 포함)
- 오늘 할 일: 오전/오후/밤 체크리스트가 이미 채워져 있음 (미완은 어제에서 이월)

30분의 "뭐부터 하지"가 0분이 된다.

### ☀️ 낮 — 진행
서연은 오전 항목을 처리한다. 완료한 작은 목표는 `projects.md`나 봇에게 체크 → `python build_dashboard.py`로 진행률 막대가 갱신된다.

### 🌛 마감 — `/close`
하루 끝에 `/close`를 부르면, 완료 항목이 산출물·수치·배운 점과 함께 `portfolio/2026-07.md`에 누적된다. 랩미팅 전날 밤 "이번 주 뭐 했지"를 재구성할 필요가 없다.

### 🗓️ 월요일 — `/weekly`
지난주 일간 기록에서 완료/미완이 자동 집계되어 회고가 채워지고, 프로젝트 목표를 바탕으로 이번 주 Top 3가 제안된다.
